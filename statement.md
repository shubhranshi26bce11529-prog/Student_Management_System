# Problem Statement
Managing student records manually can be difficult and time consuming.
the student based management system is a simple python-based application that helps users manage student information in one place.
# Scope
The system allows users to :
- add student details
- view student records
- update student details
- delete student records-
- search for a student
- add marks 
- view student results
# Target users 
this system is designed for teachers, students, and small educational institutions.
# High level features
1. student management
2. student search
3. marks management
4. result management
