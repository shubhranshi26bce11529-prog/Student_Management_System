# Student Management System
# Overview

Student Management System is a simple Python project made to store and manage student details.

In this project, we can add student details, view them, update them, delete them, and search for a student. We can also add marks and check the result of a student.

# Features
-Add student
-View students
-Update student details
-Delete student
-Search student
-Add marks
-View result

# Technologies Used
Python
Visual Studio Code
Git and GitHub

# How to Run
First, install Python on your computer.
Open the project folder in Visual Studio Code.
Open the terminal.
Type the following command:
python student_management.py
Press Enter to run the project.
